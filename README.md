# MacWindowResizer

自动调整 macOS 新建主窗口的尺寸和位置，保留后续手动调整。

应用启动时若辅助功能接口尚未就绪，会在 5 秒内每隔 200 毫秒重试，并补处理监听就绪前创建的主窗口。服务启动前已打开的窗口不会被补调；同一窗口只自动处理一次。

固定宽高模式下，未指定坐标时优先保留原位置；如果目标尺寸会超出当前屏幕可用区域，则将窗口移入可用区域后再调整尺寸。日志会读取并确认实际尺寸。

需要 macOS 13+、Rust stable 和 Xcode Command Line Tools。

编辑 `config.toml`，以应用 bundle ID 为节名，尺寸和坐标单位为逻辑点：

```toml
[com.apple.finder]
width = 860
height = 660
# x = 434
# y = 218
```

也可以为应用启用填充模式，无需指定宽高：

```toml
[com.apple.Safari]
fill = true
```

`fill = true` 会将新建主窗口调整到所在屏幕扣除菜单栏和 Dock 后的可用区域，四边各留 **8 pt**。跨屏窗口选择占据面积最大的屏幕；可用区域在每次调整时读取，随菜单栏、Dock 的位置和自动隐藏设置变化。窗口仍留在普通桌面上。

填充模式优先于同一规则中的 `width`、`height`、`x`、`y`，这些值可以保留，设置 `fill = false` 后恢复使用。省略 `fill` 时也沿用固定宽高模式，此时必须同时提供 `width` 和 `height`。保留的宽高仍须为有限正数，坐标须为有限数值。

8 pt 留白固定生效，不读取系统的“平铺窗口边缘空白”开关。部分应用可能限制窗口尺寸，实际结果以日志为准。

在项目根目录运行：

```sh
cargo enable   # 构建、安装、启动，并启用登录启动
cargo refresh  # 完整卸载后重新构建、安装并启动（修改配置后执行）
cargo disable  # 卸载应用和登录服务，重置授权并删除日志
```

首次运行需在「系统设置 → 隐私与安全性 → 辅助功能」中允许 **MacWindowResizer**；重新构建后可能需要再次授权。
